FILE SHARING GUIDE

How to send large videos without cloud storage

Open AGNIWAR on both devices, select the receiver, and choose the video. The receiver must approve. The file travels over an encrypted WebRTC connection rather than being uploaded to the signaling server. A configured TURN relay may carry encrypted traffic if direct connectivity fails.

Before sending

Allow enough free browser storage on the receiving device. Large videos may take several minutes, and performance depends on Wi-Fi, storage speed, and browser behavior. Keep both screens awake and the page open; mobile systems may suspend background tabs.

If interrupted

This version cannot resume a partial transfer. Start the transfer again. Check the chosen folder or browser Downloads. If a download was blocked, use Received files to try again. Storage quotas and browser download behavior vary, so multi-gigabyte transfers are not universally supported.

Plan for the receiver

Check the video’s size before starting. The receiving browser needs enough room for the temporary file and any saved copy, and its usable quota can be smaller than the device’s free disk space. If a large download fails, try smaller files or a browser with private file storage and sufficient free space.

What the integrity check means

AGNIWAR calculates a SHA-256 digest while sending and compares it with the receiver’s digest before offering the download. That detects accidental changes to the transferred bytes; it does not authenticate the sender or guarantee the video can be played by every device.
