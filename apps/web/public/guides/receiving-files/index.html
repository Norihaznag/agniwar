FILE SHARING GUIDE

How to receive files using agniwar

Open agniwar on the receiving device and ask the sender to open it too. Keep both pages visible and connected. Tell the sender the temporary name shown under “This device” so they can choose the right recipient.

Review the request

When an incoming request appears, check the sender’s name, file names, sizes and number of files. Choose Accept files only if you expect them; otherwise choose Decline. A familiar-looking device name is not proof of identity. Confirm sensitive transfers through another trusted channel.

Choose where files go

On browsers that offer folder selection, choose a destination after accepting. On other browsers, agniwar asks the browser to download verified files. Check your browser’s Downloads list or your device’s Files app. If a download is blocked, use the download action in Received files.

Keep an independent copy

The browser may keep a copy for downloading again, subject to storage limits and eviction. Clearing site data can remove browser-stored files. If you chose a folder, removing a history entry does not delete the copy in that folder. Keep a separate backup of important files.

If something goes wrong

Keep both screens awake and allow enough free storage. If the connection is interrupted, restart the transfer; this version cannot resume it. Try a small file first and see the discovery troubleshooting guide if the sender cannot find you.
