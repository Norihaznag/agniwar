FILE SHARING GUIDE

How to transfer files from Android to Windows

Keep your phone and computer awake and connect both to the same Wi-Fi. Open agniwar on each device. On Android, tap the Windows device, choose your files, and tap Send. Accept the request on the computer; where supported, choose a destination folder. Otherwise agniwar asks the browser to download verified files.

If the computer does not appear

Make sure both devices use the same signaling server and network. Local development uses the server computer’s directly attached IPv4 subnets for discovery. Guest isolation, VPNs, firewalls and different subnets may prevent discovery or transfer.

After the transfer

Check the chosen folder or your browser’s Downloads. If a download was blocked, use Download in Received files. For very large files, verify that the receiving browser has sufficient storage. Browser quotas and available memory may limit how large a file can be saved or downloaded.

Choose and save the right files

On the phone, the file picker may show recent items first. Use its browse control to find Downloads, Documents or the folder containing your pictures. You can select multiple files when the picker permits it. agniwar sends copies: accepting and saving them on Windows does not remove the originals from Android.

On the computer, check the chosen folder or your browser’s Downloads list. If an automatic download was blocked, use Received files to download again. If Windows warns about an unfamiliar executable or APK, verify its source before opening it. File integrity confirms that the received bytes match what was sent; it does not establish that a file is safe.
