About agniwar

agniwar is a simple browser-based utility for sending files between devices. It is for anyone who wants to move a photo, document or other file between a phone and a computer without creating an account.

How it works

Open agniwar on both devices. Choose an available device, select files and send a request. The receiver reviews and accepts or declines it. After approval, the browsers exchange files over an encrypted WebRTC data channel, usually directly.

A signaling service introduces the browsers and coordinates discovery; it does not store or process file contents. If a TURN relay is configured, it may carry encrypted traffic. Read how local file transfer works for details.

Designed for everyday use

agniwar works in supported modern browsers on phones and computers. Device visibility and transfer success depend on the network, browser permissions and available storage. Keep both pages open during a transfer and verify the recipient before sharing sensitive files.
